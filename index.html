⚙️ Setup

1. flutter pub get
2. Put google-services.json in android/app/ and GoogleService-Info.plist in ios/Runner/
3. Replace YOUR_ONESIGNAL_APP_ID in lib/main.dart
4. flutter run

⚠️ Why It Showed README Before

GitHub Pages only looks for index.html in repo root. It does NOT run index.dart. If there is no index.html, Pages shows README.md instead. Fix: upload this file as index.html in root. Keep Dart files in lib/ — not flat in root.

Correct structure:
README.md • index.html • pubspec.yaml • lib/main.dart • lib/screens/index.dart • lib/screens/nurse-login.dart …
